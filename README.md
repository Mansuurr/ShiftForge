# ShiftForge

ShiftForge — локальное приложение для Windows 10/11, которое открывает круговое меню прямо во время перетаскивания файла. Оно создаёт новую копию в выбранном формате и никогда не изменяет оригинал.

## Как пользоваться

1. Запустите ShiftForge — приложение останется в системном трее.
2. Начните перетаскивать файл в Проводнике или на рабочем столе.
3. Нажмите **Shift**, чтобы открыть кольцо форматов, или **Ctrl**, чтобы сразу открыть быстрые инструменты.
4. Наведите курсор на нужный пункт и отпустите файл.

Повторное нажатие Shift переключает кольца **Форматы → Инструменты → Пресеты**. Результат сохраняется рядом с исходником либо в подпапке `ShiftForge`, если это выбрано в настройках.

## Возможности

- Изображения: JPG, PNG, WebP, HEIC, TIFF, AVIF, BMP, PDF, ICO и GIF.
- Изображения: сжатие, изменение размера, кадрирование, цветокоррекция, аннотации, скрытие данных, фон, метаданные и офлайн-OCR в TXT.
- PDF, DOCX и текст: преобразование в PDF/DOCX/TXT/JPG/PNG, объединение, разделение, поворот, защита, извлечение картинок и сжатие.
- Видео: MP4, MKV, MOV, WebM, AVI, GIF, MP3 и WAV; обрезка, сжатие, размер, скорость, цвет, поворот, звук, кадр, метаданные и Datamosh.
- Аудио: MP3, WAV, FLAC, M4A, AAC, OGG, Opus и AIFF; обрезка, громкость, нормализация, fade, сжатие, реверс и метаданные.
- Архивы: ZIP, 7Z и TAR, безопасная распаковка ZIP/7Z/RAR/TAR и упаковка нескольких файлов.
- Пользовательские пресеты форматов, светлая и тёмная темы.
- «Волшебные папки»: новые файлы автоматически преобразуются по выбранному правилу.
- Работа полностью локальная; файлы никуда не загружаются.

## Установка

Скачайте `ShiftForge-Setup.exe` из Releases, запустите его и оставьте включённой опцию автозапуска. Установщик работает для текущего пользователя и не требует прав администратора.

## Разработка и сборка

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt pytest pyinstaller
.\scripts\fetch-windows-engines.ps1
$env:QT_QPA_PLATFORM = 'offscreen'
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m PyInstaller ShiftForge.spec --noconfirm
```

Для установщика нужен Inno Setup 6:

```powershell
& 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' installer\ShiftForge.iss
```

## Происхождение и лицензии

Интерфейс перетаскивания основан на MIT-проекте [DragShift](https://github.com/llamaboi55/DragShift). Изменения ShiftForge включают мультимедиа и архивные инструменты из открытой работы участников DragShift, русскую оболочку, OCR, Ctrl-меню, пресеты, темы и волшебные папки. Исходная лицензия сохранена в `LICENSE`, подробная атрибуция — в `NOTICE.md` и `THIRD_PARTY.md`.

FFmpeg, FFglitch и 7-Zip поставляются как отдельные локальные исполняемые компоненты в готовом установщике. Их лицензии включаются в сборку.
